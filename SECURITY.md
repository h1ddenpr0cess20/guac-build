# Security Policy

Guac Build is an independent, experimental fork and is **not** covered by xAI's
or Meta's security programs.

To report a vulnerability, use GitHub's private vulnerability reporting for this
repository:

- Go to the **Security** tab → **Report a vulnerability**, or
- <https://github.com/h1ddenpr0cess20/guac-build/security/advisories/new>

Please do not open a public GitHub issue for security reports. There are no
formal SLAs or bounties — this is a hobby fork — but reports are appreciated and
will be addressed on a best-effort basis.
